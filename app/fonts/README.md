# Inter

InterVariable.woff2 and InterVariable-Italic.woff2 are the upstream Inter variable fonts (weight 100–900), self-hosted with next/font/local for interface text and headings.

Source: https://github.com/rsms/inter/tree/master/docs/font-files

# Commit Mono

CommitMono-VF.woff2 is the upstream Commit Mono V1.43 variable font (weight 200–700, normal and italic), bundled through next/font/local.

Source: https://github.com/eigilnikolajsen/commit-mono/tree/d407cd2bf8e01ca1db70544052fbbb9606406c3b/src/fonts/fontlab

License: SIL Open Font License 1.1; see OFL.txt.
